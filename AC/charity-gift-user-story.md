# User Story - Charity Gift

## Epic

As a user, I want to donate to charity or buy charity gift cards so that I can support a cause or send a meaningful gift to someone else.

---

## 1. User Stories

### US-01: Choose charity gift type

As a donor, I want to choose between charity voucher and charity gift card so that I can follow the right flow for my intention.

### US-02: Donate to a selected cause

As a donor, I want to select a charity purpose and enter an amount so that my donation is recorded for the right campaign.

### US-03: Review payment before confirming

As a donor, I want to see the payment summary before confirming so that I understand the total amount I will pay.

### US-04: Buy charity gift cards

As a donor, I want to buy charity gift cards with a selected value and quantity so that I can give them to others.

### US-05: Send gift card directly

As a donor, I want to optionally send a gift card directly to a recipient email so that the gift can be delivered immediately.

### US-06: Track donation batches

As a donor or operations user, I want to view batch donation lists and details so that I can track how donations are distributed.

### US-07: Track gift card lifecycle

As a donor or recipient, I want to view gift card details, QR, and redemption status so that I can track the card lifecycle.

### US-08: View proof and receipt

As a donor, I want to view proof and tax receipt so that I have supporting documentation for the transaction.

### US-09: Review transaction history

As a user, I want to review charity transaction history so that I can look back at previous charity activities.

---

## 2. User Journey by Flow

### 2.1 Voucher Journey

1. Choose `Charity E-Voucher`.
2. Select a purpose.
3. Enter donation amount and currency.
4. Select payment method.
5. Confirm payment.
6. Receive success message.
7. Open batch list and inspect details if needed.

### 2.2 Gift Card Journey

1. Choose `Charity E-Gift Card`.
2. Enter card value, quantity, and currency.
3. Optionally enable direct send and enter recipient email.
4. Select payment method.
5. Confirm payment.
6. Receive success message.
7. Open card list and inspect card detail, QR, or proof if needed.

---

## 3. Motivation Behind the Stories

- Users need a clear and simple way to support charity.
- Users need confidence that payment and tracking are transparent.
- Users need post-transaction visibility for proof, receipt, and lifecycle tracking.
- Operations users need a way to inspect batches and distribution records.
